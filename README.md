# Leo Fries Meyer – Werke

Einfache Seite für die Vernissage. Adresse nach dem Veröffentlichen:
**https://leoniefriesmeyer-code.github.io/kunst/** (der QR-Code auf den Schildern führt genau hierhin).

## Angaben ändern
Alles steht in `werke.js`: Titel, Technik, Format, Jahr, Preis und Status (`''`, `'reserviert'` oder `'verkauft'`).
Fotos liegen in `bilder/` als `01.jpg`, `02.jpg` …

## Einmalig veröffentlichen (GitHub Desktop)
1. File → Add Local Repository → Ordner `kunst` → „create a repository“ → Create Repository.
2. Publish repository – Name **kunst**, Haken bei „Keep this code private“ **entfernen** (GitHub Pages braucht ein öffentliches Repository).
3. Auf github.com im Repository: Settings → Pages → Source „Deploy from a branch“ → Branch `main`, Ordner `/ (root)` → Save.
4. Nach 1–2 Minuten ist die Seite unter der Adresse oben erreichbar.

## Änderungen hochladen
Commit to main → Push origin. Nach etwa einer Minute ist die Änderung online.
